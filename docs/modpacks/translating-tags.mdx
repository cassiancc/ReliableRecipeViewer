# Translating Tags

RRV follows the common standard for tag translations adopted by Fabric and NeoForge in 1.21. These tag translations are visible in the Item Tag view, and will be shown to users when hovering over a recipe that includes item tags. The format is as follows:

```json
"tag.item.minecraft.beds": "Translation of the item tag 'minecraft:beds'"
```

It is generally recommended to translate any tag your mod provides. This standard is employed by both Fabric and NeoForge, and is supported by other recipe viewers like JEI and [EMI](https://github.com/emilyploszaj/emi/wiki/Tag-Translation).
