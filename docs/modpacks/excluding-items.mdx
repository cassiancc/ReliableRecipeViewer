# Excluding Items

## Via Tags

Items can easily be excluded from RRV using the `c:hidden_from_recipe_viewers` common [tag](https://minecraft.wiki/w/Tag_(Java_Edition)) adopted by Fabric and NeoForge in 1.21. Using this tag ensures that all recipe viewers that respect the tag (JEI, REI, EMI, EIV, RRV, etc.) will not display your item without needing dedicated integration.

RRV respects this tag for blocks, items, fluids, enchantments, and potions.

## Via Code

Mods that prefer having dedicated RRV integration (wanting to hide more complicated `ItemStack`s, or changing the index at runtime without a virtual data pack) can also make use of various methods in `ItemView` to exclude items as well.

- `ItemView.excludeItem` and `ItemView.excludeItems` exclude instances of `Item`.
- `ItemView.excludeEnchantment` exclude resource keys representing an `Enchantment`.
- `ItemView.excludePotion` and `ItemView.excludePotions` exclude holders representing a `Potion`
